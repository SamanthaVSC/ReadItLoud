# 🗣️ TTS Desktop App (PySide)

A modern desktop Text-to-Speech (TTS) application built with Python and PySide.
This project aims to provide a clean, extensible interface for offline TTS engines
such as Piper, Coqui, and other local models.

---

## ✨ Features

- 📝 Text input with real-time editing
- 🔊 Offline TTS playback
- 🎙️ Voice selection
- ⚙️ Model selection (auto/manual)
- 💾 Save generated audio
- 📊 Real-time progress feedback

---

## 🧠 Architecture

This project follows:

- Clean Architecture (core logic independent of UI)
- MVP at the UI layer (PySide)
