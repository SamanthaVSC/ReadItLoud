# 🗣️ ReadItLoud

## This demo version is only for English and Spanish

A desktop application to help people practice reading, improve their listening skills, and refine their pronunciation — powered by offline Text-to-Speech engines.

**Built with Python & PySide6**

---

## ✨ Features

- **✨ Features**
  - 🔊 **Offline TTS Playback** — Listen to text read aloud using local engines (no internet required)
  
  - 🧩 **Grammar Feedback** — Tool to help you improve your grammar
  
  - 🎯 **Pronunciation Feedback** — Tool to help you improve your pronunciation
  
  - ✍️ **Transcribe** — Convert audio files or microphone input to text
  
  - 🔄 **Translate** — Translate text between English and Spanish
